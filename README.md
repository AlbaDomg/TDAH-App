# 📖 Overview

This project was inspired by my own experience after being diagnosed with ADHD and realizing that most productivity tools weren't designed for the way my mind naturally works.

Rather than trying to adapt myself to existing tools, I decided to build one from scratch.

This project is my attempt to rethink productivity from an ADHD-first perspective, combining psychology, gamification and Artificial Intelligence to create an experience that feels supportive instead of overwhelming.

---

# 🧠 Design Philosophy

The application is built around several core principles:

- One priority at a time instead of overwhelming task lists.
- Reduce cognitive overload.
- Reward progress instead of punishing unfinished work.
- Encourage emotional regulation before productivity.
- Transform productivity into a motivating experience.
- Design specifically for ADHD, not adapt traditional productivity methods afterwards.

---

# ✨ Features

## 🎯 Focus Mode

A distraction-free workspace where users choose their main priority for the day.

Features include:

- One primary task
- Focus timers
- Scheduled reminders
- Progress tracking
- Resume previous sessions

---

## 📋 Smart Lists

Quick-access lists designed to unload mental clutter.

Examples:

- Shopping lists
- Travel checklists
- Ideas
- Notes
- Personal collections

---

## 🆘 Rescue Mode

When users feel overwhelmed, Rescue Mode immediately interrupts the current workflow and proposes a very small achievable action.

Examples include:

- Guided breathing
- Tiny first steps
- Alternative suggestions
- Returning to the main task

The objective is to reduce paralysis and help users regain momentum.

---

## 😌 Calm Space

A dedicated section focused on emotional regulation.

Includes activities such as:

- Guided breathing
- Grounding exercises (5-4-3-2-1)
- Sensory interactions
- Relaxation exercises

---

## 🏆 Achievement System

Every completed action contributes to daily progress.

The application reinforces positive habits through:

- Daily achievements
- Progress tracking
- Positive feedback
- Visual motivation

---

## ⭐ Dopamine Store

Instead of using points only as statistics, users earn Dopamine Points that can be exchanged for meaningful rewards.

The store includes:

- Unlockable themes
- Notification sounds
- Custom personal rewards
- Cosmetic improvements

This creates positive reinforcement without relying on traditional productivity mechanics.

---

## 🤖 AI Integration

Google Gemini is currently integrated to help users break down complex tasks into small, actionable steps.

Instead of facing a large or overwhelming task, that are one of the biggest sources of procrastination for many people with ADHD, the users receive a personalized sequence of manageable actions generated from the task title, making it easier to start and maintain focus.

Example:

Task:
> Build my portfolio website

AI-generated steps:

- Plan the website structure
- Design the homepage
- Create the About section
- Build the Projects page
- Add responsive styling
- Deploy the website

# 💡 Why this project is different

Most productivity applications are designed around maximizing task management.

This project focuses on minimizing cognitive friction.

Instead of asking users to adapt to the software, the software adapts to the way many ADHD users naturally approach attention, motivation and organization.
